# CoinDCX 15m Movers + 1m RSI Divergence Scanner
Checks recent 15-minute price movers among the selected CoinDCX market universe, ranks by absolute move, then scans only the Top 20 or Top 25 for confirmed 1-minute RSI-14 divergence. Pivot gap is 1–18 candles.
Render build: `npm install`; start: `npm start`.
Upload package.json, server.js, README.md in repository root and public files inside public/.
