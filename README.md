# CoinDCX 1H Sweep Radar V15 PRO

## Direction controls
- BOTH: show bullish + bearish
- BULLISH ONLY: show only bullish
- BEARISH ONLY: show only bearish
- BTC-ALIGNED ONLY: show only the direction matching BTC's latest completed 1H candle

## Scanner
- CoinDCX active USDT markets
- Previous completed 1H candle as reference
- 5m or 10m locally aggregated from 1m candles
- Wick sweep
- Same-candle or later closed-candle confirmation
- Watching and confirmed sections
- Rule-based 0-100 score
- A+ ranking
- RSI 14 / 70 / 50 / 30
- Full responsive candlestick chart
- 1H High/Low chart levels
- Auto refresh 5/10 min option
- Laptop + phone responsive

## Render
Build: npm install
Start: npm start
Node: >=18
